DeepSeek Harness 桌面版 · Desktop

项目简介

Overview

DeepSeek Harness 桌面版（dsh-desktop）是一款 Windows 桌面应用，将 dsh web 的 Web 界面封装为原生 Electron 桌面应用。

DeepSeek Harness Desktop (dsh-desktop) is a Windows desktop app that wraps the dsh web UI into a native Electron shell.

  • 双击启动，自动拉起内置 dsh web 服务，原生窗口打开界面
  • 完全自包含：内置 Electron 43 + Node.js 22 + 完整 dsh 包，不依赖系统 Node
  • 与命令行版共享 ~/.dsh（profile / 会话 / 存储全部通用）
  • Double-click to launch: auto-starts bundled dsh web and opens the UI in a native window
  • Fully self-contained: Electron 43 + Node.js 22 + complete dsh package, no system Node required
  • Shares ~/.dsh with the CLI version
