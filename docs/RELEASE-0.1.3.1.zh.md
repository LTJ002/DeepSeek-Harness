## 0.1.3.1 更新内容

基于 0.1.3（rc.8 内核）的小版本更新——插件管理、归档体验与窗口修复。

- **插件禁用名单** — 插件市场可禁用任意插件（安装按钮变「恢复」，避免误装）；「禁用」页统一管理；卸载的默认插件不再强制装回（自由卸载）
- **归档管理：检查点独立页** — 文件检查点（预览差异 → 确认回滚 → 撤销）从回滚页拆分为独立「检查点」页签；按钮行不再换行错位
- **修复：安装/卸载插件时弹出终端框** — pnpm 子进程窗口隐藏
- **修复：操作结果消息永久残留** — 回收站/回滚/检查点状态消息 8 秒后自动消失
- **修复：归档时间显示为 UTC 原始格式** — 改为本地时间显示
- **优化：启动自动创建的空会话直接删除** — 不再向回收站堆积垃圾记录
- **修复：检查点列表刷新闪屏/结果消息丢失** — 改为无感刷新
